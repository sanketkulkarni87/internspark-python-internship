# Automated File Organizer

## Project Description
This Python project automates file management tasks such as:
- Organizing files by extension
- Renaming files
- Deleting temporary files
- Generating operation logs

## Features
- Uses OS module
- Uses Exception Handling
- Generates logs automatically
- Takes user input
- Supports file sorting and cleaning

## Technologies Used
- Python
- os module
- shutil module
- logging module

## How to Run

1. Open terminal or command prompt
2. Run the following command:

python organizer.py

3. Enter folder path
4. Select operation

## Example Input

Enter folder path:
D:\NOTES AND SYLLABUS\6TH SEM\CC

Enter your choice:
1

## Example Output

Moved: notes.pdf -> file_1.pdf
Moved: image.jpg -> file_2.jpg

File organization completed successfully!
